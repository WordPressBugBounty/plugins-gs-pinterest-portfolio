== Description ==

**GS Pinterest Portfolio** brings your Pinterest pins onto your website. Enter a Pinterest username, and optionally a board name, and your latest pins appear in a clean masonry grid that keeps itself up to date. There's no Pinterest app or API key to set up.

Use it to show your work, recipes, products, mood boards or inspiration, and to send visitors to your Pinterest profile to follow you.

### How it works

1. Go to **GS Pinterest > Create New Shortcode**.
2. Enter your Pinterest username and, to show one board, its board name. Choose a theme and how many pins to show. The live preview updates as you change settings.
3. Copy the shortcode, for example `[gs_pinterest id=1]`, into any page or post, or use the GS Pinterest block or widget in your page builder.

To find a board name, look at the board's address. For `https://www.pinterest.com/jonathan/fathers-day/`, the username is **jonathan** and the board name is **fathers-day**.

### Shortcode usage

`[gs_pinterest id=1]`

In a theme file:

`<?php echo do_shortcode( '[gs_pinterest id=1]' ); ?>`

See [how to create a shortcode](https://docs.gsplugins.com/gs-pinterest-portfolio/manage-gs-pinterest-portfolio/create-new-shortcode/?utm_source=wordpress.org&utm_medium=readme&utm_campaign=gs-pinterest-portfolio&utm_content=shortcode-docs) for every option.

== Installation ==

= From your WordPress dashboard =
1. Go to **Plugins > Add New** and search for **GS Pinterest Portfolio**.
2. Click **Install Now**, then **Activate**.
3. A **GS Pinterest** menu appears in your dashboard.

= By uploading the zip file =
1. Download `gs-pinterest-portfolio.zip`.
2. Go to **Plugins > Add New > Upload Plugin**, choose the file and click **Install Now**.
3. Activate the plugin.

= By FTP =
1. Upload the `gs-pinterest-portfolio` folder to `/wp-content/plugins/`.
2. Activate the plugin from **Plugins** in your dashboard.

Then create a shortcode and add it where you want the pins to show, or add a GS Pinterest widget under **Appearance > Widgets**. See the [setup guide](https://docs.gsplugins.com/gs-pinterest-portfolio/?utm_source=wordpress.org&utm_medium=readme&utm_campaign=gs-pinterest-portfolio&utm_content=install-docs) for screenshots of each step.

== Frequently Asked Questions ==

= Do I need a Pinterest API key or developer account? =
No. Enter your Pinterest username, and a board name if you want one board, and the plugin fetches your public pins.

= How do I show pins from one board? =
Enter the username and the board name from the board's address. For `https://www.pinterest.com/jonathan/fathers-day/`, the username is **jonathan** and the board name is **fathers-day**.

= Why don't my newest pins show yet? =
Pins are saved on your site to keep pages fast, and refresh on the sync schedule you choose (daily, weekly or every 15 days). To update right away, go to **Tools** in the plugin and click **Sync data now**.

= How many pins can I show? =
Set the number in the shortcode. When no board is chosen, you can show more than 50 pins from a profile.

= Can I show my Pinterest profile or a follow button in the sidebar? =
Yes. The plugin includes 4 widgets: profile, board, single pin and follow button.

= Can pins open in a popup on my site? =
Yes, with Pro. The popup theme opens pins in a lightbox. In the free version, pins open on Pinterest in a new tab or the same window.

= Can I show private or secret boards? =
No. Only public pins and boards can be shown.

= Does it work with Elementor, Divi and other page builders? =
Yes. It has a Gutenberg block and native widgets or modules for Elementor, Divi, WPBakery, Beaver Builder and Oxygen. In any other builder, paste the shortcode.

= How do I change the templates? =
Copy a template from the plugin's `templates` folder to a `gs-pinterest` folder in your child theme and edit it there. See [template override](https://docs.gsplugins.com/gs-pinterest-portfolio/faq/?utm_source=wordpress.org&utm_medium=readme&utm_campaign=gs-pinterest-portfolio&utm_content=faq-templates).

= How do I use the shortcode in a theme template? =
Use `<?php echo do_shortcode( '[gs_pinterest id=1]' ); ?>` and replace 1 with your shortcode's ID.

= What is the difference between the free and Pro versions? =
The free version gives you the pins and board themes, 4 widgets, video pins and automatic sync. Pro adds popup, hover, pin links, grayscale and user profile themes, and priority support. See the [Pro features and plans](https://www.gsplugins.com/product/gs-pinterest-portfolio/pricing/?utm_source=wordpress.org&utm_medium=readme&utm_campaign=gs-pinterest-portfolio&utm_content=faq-pro).
